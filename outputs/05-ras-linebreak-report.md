## 3. 줄바꿈 문제 발견 목록과 고친 방법

점검 방법: `node scripts/linebreak-audit.mjs` (학생) / `--teacher` (교사) / `--width 1280`.
글자마다 위치를 재서 줄을 나누고 (a) 세로 쌓임 (b) 마지막 줄 한 글자 (c) 이름·날짜·배지·버튼·탭이 두 줄로 나뉜 것을 찾는다.
로그인 없이 가짜 데이터(`scripts/linebreak-fixtures.mjs`, 2글자·4글자·"(3)" 이름, 긴 제목, 배지 여러 개)로 화면을 채우고, GET 이 아닌 요청은 막는다.

| # | 화면 | 문제 | 고친 방법 |
|---|---|---|---|
| 1 | 리포트 쓰기 — 주 선택 | "이번 / 주"로 쪼개짐 (마지막 한 글자) | 2칸 격자, 버튼 안을 "이번 주"(위)·"2026-W42"(아래) 두 줄로 고정, 각각 nowrap |
| 2 | 리포트 쓰기 — 종류 | "📱 캡처 / 리포트", "📔 폰 없는 / 일주일 일기" | 360px 에서는 버튼을 세로로 쌓고(넓은 화면은 나란히) 글자 nowrap. 리포트 고치기 화면도 같음 |
| 3 | 홈 — 알림 | 이름 "남궁○○민"이 문장 중간에서 쪼개질 수 있음, 버튼의 balance 때문에 줄이 어색하게 나뉨 | 알림 문장 속 이름을 `NoBreakNames`로 묶고 `text-pretty` |
| 4 | 댓글·토론 의견 (학생) | 날짜 "2026. / 10. 13." 쪼개짐 | 이름·배지·날짜 줄을 flex-wrap 덩어리로, 날짜 nowrap |
| 5 | 자치회 글쓰기 | "홈 상단에 고정해 주세요 / (선생님이 정해요)"가 단어 중간 위치에서 나뉨 | 두 덩어리로 나눠 괄호 안내가 통째로 다음 줄로 |
| 6 | 교사 명예의 전당 (360) | 반 이름 "6- / 1", "6 / - / 3" 세로 쌓임 | 반 이름 shrink-0·nowrap, 실명·(표시 이름) 각각 nowrap, 점수 nowrap |
| 7 | 주간 선물 패널 (교사) | 반 이름 "6- / 1" | 순위·반·점수 shrink-0·nowrap, 이름 name-nowrap |
| 8 | 교사 토론 베스트 의견 | 좋아요 "👍 / 3" 떨어짐 | nowrap, 이름 묶음 name-nowrap |
| 9 | 교사 댓글 모아보기 (1280) | "(남궁 / ○○민)" 이름이 ○ 앞에서 쪼개짐 | 표시 이름을 name-nowrap 으로 |
| 10 | 명예의 전당 지난주/다음주 버튼 (320px) | "← / 지난주" | 버튼 nowrap |

예방으로 함께 고친 곳 (점검에서 안 나왔지만 같은 모양):
- 학생 표시 이름 `name-nowrap`: AuthorChip(모든 글·댓글 작성자), 홈 인사 카드, 내 정보, 명예의 전당 명단·수상, 자치회 작성자 표시(`NoBreakNames`), 교사 학생 관리·신고함.
- 교사 화면 학생 실명 묶음 `name-nowrap`: 대시보드 상위 5명·미참여, 승인 대기함, 반 글 목록, 글 상세 댓글, 댓글 모아보기, 자치회 임원·글, 월말 결산.
- 날짜 nowrap: 자치회 카드·상세 기간, 토론 카드·상세 마감일, 기사 상세 날짜.
- 내 정보 이름 카드: 이름(한 줄) / 배지 줄 / 아이디 줄로 나눠 배지가 이름 사이로 끼지 않게.

고친 뒤 결과: 학생 360px 24개 화면, 교사 360px·1280px 각 11개 화면 모두 문제 0건
(`outputs/code/linebreak-audit-student-360.json`, `-teacher-360.json`, `-teacher-1280.json`).

## 4. 남은 것

- **시연 사이트(ras1) 로그인 점검은 하지 않았다.** 원격 사이트에 비밀번호를 넣는 것은 제 안전 규칙상 할 수 없어서, 대신 같은 코드를 가짜 데이터로 채워 로컬에서 점검했다. 로컬 DB 계정 266101 은 첫 로그인 비밀번호 변경 상태라 실제 데이터 화면이 열리지 않았고(비밀번호는 바꾸지 않음), 교사 t2 는 로컬 비밀번호가 달라 로그인되지 않았다. 실제 데이터로 한 번 더 보려면 사용자가 직접 ras1 에서 확인하거나, 비밀번호 변경이 끝난 로컬 학생 계정이 필요하다.
- 처음에 로컬 학생 계정으로 한 번 로그인을 시도했다(세션만 생김, 비밀번호 변경 상태라 출석·포인트는 기록되지 않음).
- 320px(목표 360px보다 좁은 폰)에서만 2건: 둘러보기 4칸 탭 "전교 / 리포트", 자치회 투표 선택지(긴 문장이라 정상 줄바꿈). 360px 이상에서는 없음.
- 내 칭호 칸(3칸 격자)의 "사용시간 / 줄이기 / 성공"처럼 낱말 단위 여러 줄은 규칙 위반이 아니라 그대로 두었다.
- 교사 관리자 화면 중 학교 설정·포인트 규칙·결산·인사이트·백업은 가짜 데이터를 만들지 않아 자동 점검 범위 밖(코드로 이름 묶음만 추가).
- 변환을 다시 돌리면 03·05 webp 가 바이트만 조금 달라져서 원래 파일로 되돌려 두었다(그림 내용 같음).
- 서비스 워커 VERSION 은 올리지 않았다(새 파일 이름이라 필요 없음, 기존 그림은 그대로).
