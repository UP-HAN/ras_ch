### 주의할 점

- 서버(Lightsail, `ssh ras-server`)의 다른 앱(class-backend, class_tool DB, 다른 nginx 사이트)은 절대 건드리지 않는다.
- 서버에서 빌드하지 않는다(RAM 914MB). 로컬에서 `npm run build` 후 dist 만 업로드 → `pm2 reload ras-point` / `ras-demo`. 서버 의존성은 `npm ci`(`--omit=dev` 쓰면 마이그레이션용 tsx 가 빠진다).
- 운영에는 아직 **복원 절차가 없다**. 지금 있는 것은 DB 매일 03:10·사진 일요일 03:20 자동 백업(`deploy/backup.sh`, 30일 보관)뿐이라 DB 와 사진이 짝이 맞지 않을 수 있다. 백업 지점 기능을 만들기 전에 운영 데이터를 크게 바꾸는 작업은 조심한다.
- `.env`(로컬·서버)와 SSH 키는 git 에 없다. 새 컴퓨터는 `docs/SETUP-NEW-PC.md` 참고.
- 로컬 포터블 MySQL 은 임시 폴더에 있어 바이너리가 지워질 수 있다(zip 은 남음).
