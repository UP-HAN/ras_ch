# Claude Code 첫 프롬프트 (복사해서 붙여넣기)

## 1) 처음 열었을 때 — 문서 파악 + S0 계획

```
CLAUDE.md와 docs/PRD.md, docs/PLAN.md, docs/TASKS-phase1.md를 읽고 나서,
이 프로젝트를 한 문단으로 요약하고, 1차 개발에서 가장 위험하다고 보는 지점 3가지를 말해 줘.
그 다음 TASKS-phase1.md의 S0(0-1~0-4)를 계획 모드로 잡아 줘:
만들 파일 목록, DB 스키마 초안(테이블·컬럼·인덱스), npm 스크립트 구성.
내가 확인하기 전에는 코드를 쓰지 마.
```

## 2) 계획을 확인한 뒤

```
계획대로 S0를 구현해 줘. 끝나면 npm install, docker compose up, db:migrate, db:seed, npm run dev 가
실제로 되는지 직접 실행해서 확인하고, TASKS-phase1.md의 0-1~0-4를 [x]로 바꿔 줘.
```

## 3) 이후 스프린트마다 (예: S1)

```
TASKS-phase1.md의 S1(1-1~1-6)을 진행하자. 먼저 PRD의 AUTH-01~07, 3.1 계정 규칙, ADM-01을 읽고
구현 순서와 API 목록을 계획 모드로 보여 줘. 확인 후 하나씩 구현하고, 항목마다 테스트를 붙이고,
끝날 때마다 체크박스를 갱신해 줘.
```

## 4) 막혔거나 PRD와 충돌할 때

```
지금 구현하려는 것이 PRD의 [ID]와 어떻게 다른지 설명하고, 선택지를 2~3개 줘. 결정하기 전엔 코드 쓰지 마.
```

## 5) 스프린트 마무리

```
이번 스프린트에서 만든 것, 충족한 PRD ID, 남은 것, 다음 스프린트에 넘길 리스크를 5줄로 정리하고
docs/PROGRESS.md에 날짜와 함께 추가해 줘. 그리고 커밋해 줘.
```
