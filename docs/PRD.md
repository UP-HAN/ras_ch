**2. 제품 목표와 범위**

**2.1 목표**

- 학생이 폰에서 3분 안에 주간 리포트를 올릴 수 있다 (캡처 2장 + 숫자 2개 + 글 100자)

- 담임교사가 PC에서 반 전체 승인 대기 건을 15분 안에 처리할 수 있다

- 담당 교사가 클릭 3번으로 월간 결산(포인트 상위 선물 + 3부문 명예의 전당)을 확정할 수 있다. 주간은 자동 게시라 손댈 것이 없다

- 포인트는 모두 원장(ledger)에 남아 언제든 재계산·감사할 수 있다

**3.1 계정 규칙**

- 학생 ID: 학년도 + 학년 + 반 + 번호 조합(예: 26-3-02-15) 또는 관리자가 CSV로 지정한 값

- **표시 이름(확정): 성 + 마스킹** — "3-2 김○롱" 형식. 규칙: 성 1글자 그대로, 이름의 첫 글자를 ○로, 마지막 글자 그대로(2글자 이름 "김하" → "김○", 4글자 이상 이름은 가운데 모두 ○). 시스템이 name에서 자동 생성해 display_name에 저장, 학생은 변경 불가

- 같은 반에 마스킹 결과가 같은 학생이 둘 이상이면 번호를 병기한다("3-2 김○롱(7)" / "3-2 김○롱(15)") — 시스템이 자동 판단

- 마스킹 이름은 학생 화면 전체(게시글·댓글·명예의 전당·토론·안건)에 공통 적용. 교사·관리자 화면과 CSV·상장 PDF에는 실명 표시. 학부모 안내장에 "앱 화면에는 이름이 일부 가려져 표시됨"을 명시

- 초기 비밀번호: 관리자가 CSV에 지정하거나 자동 생성(4자리 숫자 + 학생 이름 첫 글자 등), 첫 로그인 시 변경 강제

- 교사 계정: 관리자가 생성, 이메일 형식 ID, 비밀번호 8자 이상

- 학년 승급·전출입: 관리자가 학생 상태(active / transferred / graduated) 변경, 기록은 보존

**4. 사용자 시나리오**

**4.1 학생 — 주간 리포트 올리기**

1.  일요일 저녁, 5학년 학생이 폰에서 앱을 연다. 홈 상단에 "이번 주 리포트를 아직 안 올렸어요" 카드가 보인다

2.  카드를 누르면 캡처 안내 화면이 나온다(삼성 디지털 웰빙 / 아이폰 스크린타임 예시 이미지 + "이 두 화면만 캡처").

3.  갤러리에서 캡처 2장을 선택하고, 하루 평균 사용시간(3시간 9분 → 시/분 입력), 가장 많이 쓴 앱(네이버 웹툰)을 입력한다

4.  성찰 글 칸에 문장 도우미가 보인다. 100자 이상 쓰고 "다음 주 목표"를 한 줄 적는다

5.  제출하면 "선생님 확인 후 게시돼요. 예상 포인트 +30P" 안내가 뜬다

6.  월요일 담임이 승인하면 홈에 "+30P 획득! 지난주보다 25분 줄었어요 +10P" 알림 카드가 뜬다

**4.2 학생 — 기사 쓰고 반응하기**

1.  토요 스포츠데이에 다녀온 4학년 학생이 "글쓰기 \> RAS 기사"를 누르고 "체험 후기" 템플릿을 고른다

2.  제목, 영역 태그(S), 본문 200자, 사진 2장을 올린다. 승인 후 전교 기사 목록에 뜬다

3.  다른 학생들이 기사에 엄지척을 누르고 댓글을 단다. 댓글은 10자 이상만 등록되고, 금칙어가 있으면 등록되지 않는다

**4.3-1 학생자치회 임원 — 1차 검토**

1.  5학년 담당 임원이 앱을 열면 "검토 대기 9건" 카드가 보인다. 체크리스트(캡처 2장이 맞는가 / 글자 수 / 나쁜 말·개인정보 없음 / 목표 한 줄)가 카드마다 붙어 있다

2.  항목을 체크하고 "통과"를 누르면 담임 선생님 대기함으로 넘어간다. 애매한 글은 "보류 요청"에 이유(캡처가 다른 화면이에요)를 적어 넘긴다

3.  자기 글·같은 반 글은 목록에 뜨지 않는다. 검토 1건당 +1P, 하루 10건까지 인정된다

**4.3-2 담임교사 — 월요일 아침 2차 승인**

1.  PC에서 로그인하면 "승인 대기 12건 (1차 통과 9 · 보류 요청 2 · 미검토 1)" 배지가 보인다

2.  1차 통과 9건은 임원 체크 결과가 초록색으로 표시되어 훑어보기만 하고 "1차 통과 전체 승인"을 한 번에 누른다

3.  보류 요청 2건은 임원 메모를 보고 "승인" 또는 "반려(사유 선택: 캡처 불일치 / 글자 수 부족 / 부적절 내용)"를 누른다. 미검토 1건은 직접 본다

4.  우리 반이 교사 단독 모드라면 1차 검토 없이 전부 바로 대기함에 뜨고, 개별·일괄 승인으로 처리한다. 승인과 동시에 포인트가 자동 지급된다

5.  특별히 성찰이 좋은 학생에게 "칭찬 포인트 +10P (사유: 구체적인 목표 설정)"을 준다

**4.4 담당 교사 — 월간 결산·명예의 전당**

1.  매주 월요일 00:05 시스템이 지난주 포인트 TOP(학년별 10명)을 명예의 전당 주간 탭에 자동 게시한다. 기본은 게시만이고 관리자는 손대지 않아도 된다

2.  선물을 주고 싶은 주에는 관리자가 명예의 전당 주간 탭에서 "이번 주 선물 주기"를 눌러 학년별 인원(기본 3명)이나 개별 학생을 고르고 확정한다. 확정된 학생에게 선물 표시와 WEEKLY_GIFT 포인트가 붙고 선물 명단이 출력된다

3.  월초 1일 00:05 시스템이 지난달 결산 초안을 만든다 — ① 월간 포인트 상위(학년별 기본 5명, 선물 대상) ② 폰프리 실천왕·RAS 기자·참여왕 후보(학년별 상위 5명, 점수·근거 포함)

4.  관리자가 "월간 결산" 화면에서 선물 인원 수를 조정하고, 3부문 선정자를 학생자치회 회의 결과를 반영해 고른 뒤 "확정"을 누른다

5.  확정되면 명예의 전당 월간 탭 게시, 선정자 알림 카드, 상장 PDF·선물 명단(반별 정렬, 실명) 출력

**4.5 학생 — 뉴스 토론방에서 투표하고 의견 쓰기**

1.  수요일 아침, 홈 카드에 "오늘의 토론: 학교에 스마트폰 보관함이 꼭 필요할까?"가 뜬다. 누르면 쉬운 설명 200자와 생각 열기 질문 2개가 보인다

2.  찬성/반대 버튼 중 하나를 누른다(+1P). 현재 찬반 비율 막대가 바로 보인다

3.  "나는 \_\_\_에 찬성해요. 왜냐하면 \_\_\_" 도우미를 채워 의견 댓글을 쓴다(+3P). 다른 친구 의견에 좋아요를 누른다

4.  다음 주 담당 교사가 베스트 의견 2개를 뽑으면 "+10P 베스트 의견 선정" 알림 카드가 온다

**4.6 담당 교사 — 다음 주 토론 주제 승인**

1.  금요일 오전, 관리자 화면 "토론 주제" 메뉴에 "다음 주 후보 6개 도착" 배지가 뜬다

2.  후보 카드마다 제목·설명·유형·질문·출처가 보인다. 3개를 고르고, 한 개는 문구를 살짝 고친 뒤 "승인·예약"을 누른다

3.  월·수·금 08:00 순서로 예약된 것을 확인한다. 승인을 깜빡하면 주제 은행에서 자동으로 채워진다는 안내가 보인다

**4.7 학생자치회 임원 — 초롱 슈퍼스타 홍보글 올리기**

1.  자치회 임원 학생이 "글쓰기 \> 자치회 게시판"에서 유형 "홍보"를 고르고 포스터 이미지와 안내문을 올린다. 게시 기간을 2주로 설정한다

2.  담당 교사가 승인하면 홈 상단에 고정 배너로 뜨고, 학생들이 좋아요·댓글(교사가 켠 경우)로 반응한다

**4.8 학생 — 매일 들어와서 읽고, 설문에 답하기**

1.  아침에 앱을 열면 "오늘 출석 +2P" 카드가 뜬다. 연속 5일째라 작은 불꽃 배지가 붙어 있다

2.  우리 반 리포트 두 개를 끝까지 읽으니(각 10초 이상 머무름) "읽기 +1P"가 두 번 쌓인다. 오늘은 5개까지 인정된다는 안내가 보인다

3.  홈에 "설문: 초롱 슈퍼스타 공연 요일 정하기(학생자치회)" 카드가 있다. 3문항에 답하니 +10P가 들어온다

**4.9 학생자치회 임원 — 이달의 회의 안건 의견 받기**

1.  회의 2주 전, 임원이 "자치회 게시판 \> 이달의 안건"에서 안건 3개를 등록한다(예: 점심시간 운동장 사용 규칙 / 폰프리 실천 약속 보완 / 플리마켓 부스 아이디어). 담당 교사가 승인한다

2.  학생들이 안건마다 의견을 쓰고(+3P), 다른 친구 의견에 좋아요를 누른다. 임원은 의견을 "회의 자료"로 묶어 출력한다

3.  회의 뒤 임원이 각 의견에 "채택 / 보류 / 회의에서 논의함" 표시를 하고 결과 보고 글을 올린다. 채택된 제안을 낸 학생에게 +20P가 지급된다

**7.2 이 달의 폰프리 실천왕 점수**

- 자격: 해당 월 리포트 승인 3건 이상

- 점수 = 성실성(승인 리포트 수 × 10) + 변화(월초 첫 리포트 대비 월말 마지막 리포트 사용시간 감소율 × 100, 최대 40) + 성찰(교사 평가 1~3점 × 10, 없으면 20) + 공감(받은 좋아요 + 댓글 수, 최대 20)

- 학년별 상위 5명 추천, 관리자가 1~2명 확정

**7.3 이 달의 RAS 기자 점수**

- 자격: 해당 월 기사 승인 1건 이상

- 점수 = 기사 수 × 10 (최대 40) + 기사가 받은 엄지척 합(최대 40) + 댓글 수 합(최대 20) + 관리자 추천 기사 지정 시 +20

**7.4 이 달의 참여왕 점수**

- 자격: 해당 월 리포트·기사 승인 0~1건 (글쓰기 활동이 적은 학생 우선)

- 점수 = 댓글 수(토론 의견·안건 의견 포함) × 3 (최대 60) + 좋아요 누른 수 × 1 (최대 30) + 내 댓글이 받은 좋아요 × 2 (최대 30) + 토론 투표 참여 주제 수 × 2 (최대 20) + 베스트 의견 × 10 (최대 20) + 출석 일수 × 1 (최대 25) + 읽은 글 수 × 0.5 (최대 20) + 설문 참여 × 5 (최대 15)

- 읽기·출석은 상한을 낮게 두어 "켜 두기만 하는" 활동으로는 참여왕이 될 수 없게 한다

- 실천왕·기자 선정자와 중복 시 제외

**7.5 구현 방식**

- 이벤트 기반: 승인/좋아요/댓글 등 도메인 이벤트 발생 → \`PointService.apply(event)\` → 규칙 조회 → 상한 검사(같은 주차/일자 원장 합산) → 원장 insert

- 상한 검사는 원장을 주차·일자·근거 객체 기준으로 집계해 판단(별도 카운터 테이블 두지 않음 → 재계산 가능)

- 회수는 원 원장 행의 \`reversal_of\` 를 가리키는 음수 행으로 기록

- 주간 TOP은 \`weekly_scores\`에 자동 스냅샷, 월간 결산은 \`monthly_settlements\`/\`monthly_scores\`에 확정 후 불변 스냅샷 저장

UI는 Tailwind CSS                                                                                                                                                                                                                                  |

**11.1 용량 추정**

- 학생 812명(3~6학년) × 주 2장 × 300KB(리사이즈 후) ≈ 주 480MB, 학기(16주) ≈ 7.7GB → 디스크 20GB 이상 확보 또는 오브젝트 스토리지 사용

- 원장 행: 학생 1인 주 30행 × 800명 × 16주 ≈ 38만 행/학기 — MySQL에서 문제 없음

**초롱 RAS 포인트 참여 안내 및 학부모 동의**

학부모님께. 본교는 경기도교육청 라스(R독서·A예술문화·S스포츠) 교육과 학생자치회 주도 폰프리스쿨 실천의 하나로, 3~6학년 학생이 참여하는 웹앱 "초롱 RAS 포인트"를 운영합니다. 학생들은 이 앱에서 매주 자신의 스마트폰 사용 습관을 돌아보는 글을 쓰고, 학교의 독서·예술·스포츠 활동을 기사로 기록하며, 친구의 글에 응원 댓글을 달고, 뉴스 토론 주제에 의견을 냅니다. 활동은 포인트로 모여 매달 명예의 전당에 소개됩니다.

**동의가 필요한 부분**

- "폰프리 주간 리포트"에서 학생은 자기 스마트폰의 사용 시간 화면(디지털 웰빙 / 스크린 타임)을 캡처해 올릴 수 있습니다. 이 화면에는 어떤 앱을 얼마나 사용했는지가 나타나므로, 이미지 업로드에 대해서만 학부모님의 동의를 받습니다

- 동의하지 않으셔도 자녀는 앱의 다른 활동(기사, 댓글, 토론, 설문 등)에 모두 참여할 수 있으며, 주간 리포트는 캡처 없이 글로만 쓰는 "폰 없는 일주일 일기" 방식으로 참여합니다

- 앱에는 학년·반·번호·이름만 저장하며 연락처 등 다른 정보는 수집하지 않습니다
