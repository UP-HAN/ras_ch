# 초롱 RAS 포인트 교사 화면 QA 수정 요청

- 대상: https://ras1.ches.es.kr 교사/관리자 화면 (`/teacher/**`)
- 점검일: 2026-09-27, 계정: 한의표(관리자·승인 권한), 데스크톱 1345px
- 콘솔 오류/HTTP 4xx·5xx 없음. 아래는 기능·데이터·문구 이슈이며, 우선순위(P0 > P1 > P2) 순으로 정리.
- 각 항목: **현상 → 기대 동작 → 수정안**. 재현 경로 포함.

## P0. 반드시 수정

### 1. 학생 관리: 파괴적 동작에 확인 단계 없음
- 경로: `/teacher/students` → 반 선택 → 행의 **비밀번호 초기화**
- 현상: 클릭 즉시 비밀번호가 초기화되고 임시 비밀번호 모달이 뜸. 확인 창 없음. (QA 중 6-1 1번 류다은 계정이 실제로 초기화됨)
- 기대: "OOO 학생의 비밀번호를 초기화할까요? 학생은 기존 비밀번호로 로그인할 수 없게 돼요." 확인 후 실행.
- 수정안:
  - `비밀번호 초기화`, `이 반 학생 모두 지우기`, 학생 수정 모달의 `계정 삭제` 세 곳 모두 확인 모달(취소/실행) 추가.
  - `이 반 학생 모두 지우기`는 반 이름 입력 확인(예: "6-1" 입력) 같은 2단계 확인 권장. 버튼도 테이블 헤더에서 분리하고 danger 스타일.
  - 수정 모달의 `계정 삭제`는 취소/저장 버튼 그룹과 시각적으로 분리.

### 2. 신고함: "글 보기" 링크가 교사 계정에서 동작하지 않음
- 경로: `/teacher/reports` → 카드의 **글 보기** (`href="/posts/211"`, `/posts/167`)
- 현상: 교사 세션에서 `/posts/:id`로 이동하면 `/teacher`(대시보드)로 리다이렉트됨. 신고된 글/댓글 원문을 확인할 방법이 없음.
- 기대: 교사가 신고 대상 글과 해당 댓글을 읽을 수 있어야 함.
- 수정안 (택1):
  - A. `/posts/:id` 라우트 가드에서 교사 역할 허용(읽기 전용 렌더링).
  - B. 교사용 상세 라우트 `/teacher/posts/:id` 신설 후 신고함·반 글 목록·댓글 모아보기에서 이 경로로 링크.
  - 댓글 신고의 경우 `#comment-{id}` 앵커로 스크롤 및 하이라이트.

### 3. 승인 대기함: 기사(article) 대기 건이 목록에서 빠짐
- 경로: `/teacher/pending` → 6-8 선택
- 현상: 대시보드는 "승인 대기 3건(48시간 지남 3건)", 대기함에는 2건(위다인, 피지원)만 표시. `/teacher/posts` 6-8 전체 필터에는 "4번 변준영 · (주차 없음) · 대기 · 전교"가 추가로 존재 → 주차 없는 글 = 기사 유형으로 추정. 사이드바 배지 11건 vs 대기함 실제 합계 10건도 동일 원인.
- 기대: 대시보드/사이드바 배지/대기함 목록이 같은 쿼리 조건을 사용해 숫자가 일치해야 함.
- 수정안:
  - 대기함 목록 API가 `type='report'`만 필터링하고 있다면 `article`(및 기타 승인 대상 유형) 포함.
  - 목록 카드에 유형 배지(리포트/기사/일기형) 표시.
  - 배지·대시보드·대기함이 공통 `pendingCount(classId)` 함수/쿼리를 공유하도록 리팩터링.

### 4. 신고함: 동일 대상 신고가 카드로 분리되어 처리 충돌 가능
- 경로: `/teacher/reports`
- 현상: 한 댓글(예: 6-6 백승현)을 3명이 신고 → 카드 3장, 각각 유지/숨김/삭제 버튼. 한 장은 "유지", 다른 장은 "삭제"를 누를 수 있음.
- 기대: 신고 대상(글/댓글) 단위로 1장, 그 안에 신고 이유 목록(신고자 N명).
- 수정안: `target_type + target_id`로 group by. 카드 헤더에 "댓글 신고 3건", 본문에 사유 리스트, 액션 버튼은 카드당 1세트. 처리 시 해당 그룹의 모든 report 행 상태를 함께 갱신.

## P1. 데이터·표시 불일치

### 5. 대시보드 "이번 주 상위 5명"이 이번 주 데이터가 아님
- 경로: `/teacher` (6-1, 6-6)
- 현상: "이번 주 상위 5명"에 "미참여 학생(이번 주 리포트 없음)"으로 표시된 학생이 포함됨(6-6 구본우 1위이자 미참여).
- 수정안: (a) 이번 주 획득 포인트 기준으로 집계하거나 (b) 제목을 "누적 포인트 상위 5명"으로 변경. 명확히 한 가지로.

### 6. "반 평균 포인트" 값이 페이지마다 다름
- 6-1 기준: 대시보드 151.7P(2026-W39) / 통계 548P(이번 달) / 명예의 전당 135.43P(지난주 W38)
- 수정안: 라벨에 기준을 명시. 예: "이번 주 평균 획득 포인트", "이번 달 평균 포인트", "지난주(W38) 평균". 공통 포맷터 `avgPointsLabel(period)` 사용.

### 7. 댓글 모아보기: 원글 유형·작성자 표시 오류
- 경로: `/teacher/comments`
- 현상: 자치회 공지/토론 주제에 달린 댓글의 원글이 "리포트 · 10월 폰프리 챌린지 같이 해요! ()"로 표시됨. 유형이 '리포트'로 잘못 표기되고 작성자 괄호가 비어 있음.
- 수정안: 원글 유형 매핑에 `council_post → 자치회`, `news_topic → 토론`, `article → 기사` 추가. 작성자가 없으면 괄호 자체를 렌더링하지 않음.

### 8. 반 글 목록: 유형 컬럼 없음, 상세 진입 불가, 정렬 역순
- 경로: `/teacher/posts`
- 현상: 주차가 빈 행이 다수("2번 김민재 / (빈칸) / 게시 / — / 전교") → 기사로 추정되지만 구분 불가. 행 클릭 불가. 오래된 주차(W33)부터 정렬.
- 수정안: `유형` 컬럼 추가(리포트/기사/일기형), 기사는 주차 대신 게시일 표시. 제목/학생 셀을 상세(#2의 교사용 상세 라우트) 링크로. 기본 정렬 최신순.

### 9. 금칙어: 삭제 불가, 빈 입력 피드백 없음
- 경로: `/teacher/admin/banned-words`
- 현상: 끄기/켜기만 있고 삭제 없음. 빈 값으로 "추가" 클릭 시 아무 반응 없음. (QA로 추가된 "QA테스트단어"(꺼짐) 삭제 요망)
- 수정안: 행에 `삭제` 버튼(확인 모달) 추가. 빈 값·중복 값은 인라인 오류 메시지 표시, 추가 버튼은 입력 없을 때 disabled. 중복 추가 방지.

### 10. 목록 50건 상한에서 잘림 (페이지네이션 없음)
- 경로: `/teacher/comments`(6-1 전체 50건), `/teacher/posts`(6-8 전체 정확히 50건)
- 수정안: API에 `page/limit` 또는 커서 파라미터 추가, UI에 "더 보기" 또는 페이지네이션. 총 건수 표시.

### 11. 월간 결산: 결산 불가 월에도 "초안 다시 만들기" 활성
- 경로: `/teacher/admin/settlements` → "2026년 9월 →"
- 현상: "이 달은 아직 끝나지 않았거나… 지난달 이전만 결산할 수 있어요" 문구와 함께 `초안 다시 만들기` 버튼이 활성. 10월(미래)로도 계속 이동 가능.
- 수정안: 현재 월 이후는 버튼 숨김/비활성. 다음 달 이동 버튼은 "지난달"까지만 허용.

### 12. 학생 CSV 등록 미리보기 집계·검증
- 경로: `/teacher/admin/students-import`
- 현상: 오류 행이 하나라도 있으면 정상 행도 "신규 0 · 갱신 0"으로 표시됨. `학부모동의=X` 같은 잘못된 값이 오류로 잡히지 않음.
- 수정안: 오류 행과 무관하게 정상 행은 신규/갱신 집계에 포함(등록 버튼은 기존처럼 오류 있으면 비활성 유지). `학부모동의`, `기자단`은 Y/N 외 값이면 오류.

### 13. 승인 대기함 UX
- 반려 모달: 사유 미선택·미입력 상태에서도 `반려하기` 활성 → 사유(프리셋 또는 5자 이상 직접 입력) 없으면 disabled.
- 반려 모달: ESC로 닫히지 않음 → `Escape` 키 및 배경 클릭으로 닫기.
- `전체 선택` 후 라벨이 그대로 → 선택 상태에 따라 "전체 해제"로 토글.

### 15. 포인트 규칙 상한 라벨
- "7일 연속 출석 · 글·댓글당 1회", "설문 제출 · 글·댓글당 1회", "월간 … 선정 · 달 1회" 등 `per_object` 범위 라벨이 글과 무관한 규칙에도 "글·댓글당"으로 표기.
- 수정안: 규칙 카테고리별 라벨 매핑(출석→"연속 7일마다 1회", 설문→"설문당 1회", 선정→"선정당 1회").

### 16. 접근성 라벨 (통계, 실천 변화 리포트 막대 그래프)
- 데이터 없는 주가 "2026-W28 없음분", "W33 없음%"로 읽힘.
- 수정안: 값이 null이면 aria-label을 "2026-W28 데이터 없음"으로.

### 17. 자치회
- 사이드바 "자치회" vs 페이지 h1 "학생자치회" → 하나로 통일.
- 게시 기간이 "9. 22. 오전 01:04 ~ 10. 7. 오전 01:04"로 표시(제출 시각은 9. 21. 오전 10:04). 서버 UTC 시각을 그대로 표시하는 것으로 의심 → `Asia/Seoul`로 변환해 표시하거나 날짜만 표시.
- 임원 지정 학생 드롭다운에 이미 임원인 학생이 그대로 노출 → 제외 또는 "(현재 회장)" 표기.

### 18. 공지·문구
- 아이폰 캡처 안내 "주 에서" → "주에서" (띄어쓰기 오타, 기본 문구 seed 수정).
- 시작일이 미래인 공지 상태가 "기간 밖" → "예정"으로 구분 (종료 지난 것만 "기간 밖"/"종료").

### 19. 명예의 전당
- 주간 TOP 기본 주가 38주차(지난주)인데 하단 섹션 제목은 "이번 주 선물 주기" → "38주차 선물 주기"처럼 선택된 주차를 표기.
- "학년별 인원 3"인데 이미 4명 수령 → 수동 추가분은 "직접 선택 1명" 등으로 구분 표시.

### 20. 댓글 모아보기 필터
- 반 버튼 옆에 "3-4학년군/5-6학년군"이 같이 있어 혼동. 학교에 3-4학년이 없으면 숨김. 학년군과 반은 그룹을 나누고 "범위" 라벨 부여.
- 상태 필터(전체/신고됨/금칙어 근접)의 "전체"가 범위 필터를 초기화하지 않는 점은 의도라면 두 그룹을 시각적으로 분리.

### 21. 토론 주제 페이지 길이
- 마감 토론 6개 × 의견 20개가 모두 펼쳐져 렌더링(약 525줄).
- 수정안: 마감 토론은 아코디언(기본 최신 1개만 펼침) 또는 페이지네이션. 상단 마감 토론(최신순)과 하단 게시 일정(오래된순) 정렬 방향 통일.
- "새 주제 추가"에서 빈 폼 제출 시 아무 반응 없음 → 필수 필드 인라인 오류 표시.

### 22. 공통
- 반 선택 상태가 URL에 없어 새로고침 시 6-1로 초기화 → `?class=6-8` 쿼리 파라미터로 동기화. 선택된 반 버튼에 `aria-pressed="true"`.
- 모든 페이지 `<title>`이 "초롱 RAS 포인트"로 동일 → "승인 대기함 · 초롱 RAS 포인트" 형태로 페이지별 설정.
- 통계 CSV(`/api/v1/teacher/classes/:id/export.csv`)에 UTF-8 BOM 없음 → Excel 한글 깨짐 방지를 위해 `\uFEFF` 선행.
- 학교 설정 반 배정 표: 반마다 교사 8명 체크박스 나열 → 멀티셀렉트/칩 UI로 축약.
- 날짜 표기 "2026. 9. 23. 오후 4:46:00" → 초 단위 제거, 공통 포맷터 사용.

## 정상 확인 항목 (참고)
승인 대기함 이력/반려 모달 열기, 칭찬 포인트 모달(한도 안내), 학생 수정 모달, 통계 CSV 다운로드, CSV 등록 헤더·범위 검증 및 오류 시 등록 버튼 비활성, 자치회 필터·내용 보기, 명예의 전당 4개 탭, 월간 결산 8월 확정 내역, 비밀번호 바꾸기 페이지 이동/취소, 전 페이지 가로 오버플로우 없음.
